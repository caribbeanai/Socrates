# Brand assets

| File | Use |
|------|-----|
| `socrates.png` | The original "constellation portrait" artwork — the particle bust of Socrates with the QUESTION / REASON / CRITIQUE / REFLECT loop. **Used as the banner in the root `README.md`.** |
| `socrates.svg` | A self-contained vector fallback (wordmark + reasoning-loop) that renders inline anywhere and scales cleanly. Kept as a lightweight alternative. |

## Swapping the banner

The root `README.md` references `assets/socrates.png`. To fall back to the
vector logo, change that image line from `assets/socrates.png` to
`assets/socrates.svg`.

Keep artwork under a few hundred KB where possible so clones stay light.
